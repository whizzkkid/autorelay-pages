# AutoRelay 노드 배치 (배포용 빌드)

https://whizzkkid.github.io/autorelay-pages/

BS·MS1·MS2를 지도에 찍으면 링크 e-SNR(지형 단면 전파 모델, EESM), 채널 점유시간 표 다익스트라 토폴로지,
드론 중계기 최적 위치를 브라우저에서 바로 계산합니다. 이 저장소는 자동 생성된 정적 파일만 담고 있습니다
(`scripts/build_dist.py`로 생성, 직접 수정하지 마세요).
